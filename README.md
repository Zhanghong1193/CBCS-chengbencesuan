# 检测项目成本与毛利测算系统

面向第三方检测实验室的内部 Web/PWA。系统统一管理项目价格、试剂、耗材、人工、外包及其他内部成本，并按不同价格档位计算单例毛利、毛利率和相对市场指导价折扣。

## 本地启动

1. 安装 Node.js 24 和 pnpm。
2. 在本目录执行 `pnpm install`。
3. 执行 `pnpm build`。
4. 双击 `启动成本测算.cmd`，或执行 `pnpm start`。
5. 浏览器打开 `http://localhost:8787`。

首次启动会创建用户名为 `admin` 的管理员。生产使用时请预先设置环境变量 `INITIAL_ADMIN_PASSWORD`；如果未设置，系统会在首次启动的终端中输出随机初始密码。数据库默认保存在 `data/cost-margin.db`，可用 `DATABASE_PATH` 指定其他位置。

## 常用命令

- `pnpm test`：运行计算、验证、权限、版本、导入导出及接口测试。
- `pnpm typecheck`：运行 TypeScript 类型检查。
- `pnpm build`：构建前端和服务端生产文件。
- `pnpm start`：启动已构建的单进程服务。

## 数据口径

- 所有销售价格均为不含税单价。
- 试剂和耗材采购价按含税价格直接参与成本计算。
- 汇总和导出默认使用单例金额，并只取项目最新已完成版本。
- 完成版本不可覆盖；修改时从完成版本创建新草稿。
- 系统不提供离线编辑，PWA 仅用于安装到桌面或手机主屏幕。
